# coniferous_tree_gen
uses blender 4.5 to run 3 scripts to generate your branches/billboards, texture them, and than assemble into either different coniferous trees with a script to assemble it all in unity 2017<br><br>

make sure you run the files in order from 1 -> 2 -> 3   which will than give the final tree result and export of fbx and baked pngs<br><br>
use the unity script make sure its in Assets/Editor and that will add a treesetupwizard under Tools so you can autogen your prefab by browsing to your blender output path.
